Использованные элементы интерфейса
Для построения пользовательского интерфейса применялись стандартные виджеты Flutter:

Text - вывод текстовой информации

Card - карточки для отображения товаров

TextField - поля для ввода данных

ElevatedButton - основные кнопки действий

IconButton - кнопки с иконками

GestureDetector - обработка жестов и нажатий

GridView - сетка для отображения товаров

BottomNavigationBarItem - элементы нижней навигации

Image - отображение графических элементов

Особенности реализации
При разработке удалось воспроизвести все основные экраны согласно дизайн-макетам. Единственным отклонением стала невозможность реализации экрана-заставки (сплеш-скрина) из-за технических сложностей с импортом и отображением логотипа приложения.
